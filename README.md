# SEO Content AI - WordPress Plugin

A powerful WordPress plugin that allows you to easily upload and publish SEO-optimized content generated by SEO Content AI.

## Description

The SEO Content AI WordPress plugin provides a seamless way to import and publish AI-generated, SEO-optimized content directly to your WordPress site. This plugin works in conjunction with the SEO Content AI platform to ensure your content is fully optimized for search engines.

## Features

- Simple drag-and-drop JSON file upload
- Bulk content import
- Customizable post status (Draft/Publish)
- Category assignment
- Progress tracking during upload
- Detailed upload results
- User-friendly admin interface

## Installation

1. Download the plugin files
2. Upload the plugin to your WordPress plugins directory (`/wp-content/plugins/`)
3. Activate the plugin through the WordPress admin panel
4. Navigate to "Content Uploader" in your WordPress admin menu

## Usage

1. Generate your SEO-optimized content using [SEO Content AI](https://seocontent.ai)
2. Download your content in JSON format
3. In WordPress admin, go to "Content Uploader"
4. Drag and drop your JSON file or click to browse
5. Select post status and category
6. Click "Upload Content" to import your articles

## Requirements

- WordPress 5.0 or higher
- PHP 7.0 or higher
- JSON file generated by SEO Content AI
